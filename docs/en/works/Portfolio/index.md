# Portfolio 2026
##### 2026

## Starting point

I wanted to turn myself into a website. Rather than presenting a neutral collection of finished work, it should make my way of thinking, designing and telling stories visible.

## Idea and story

The website is a digital self-portrait. Each project has its own typeface, cover and, where appropriate, animated preview. The site also has a night-time version, making the cycle of the day part of its design.

## Making the work

I designed separate media formats for desktop and smartphone so that images and transitions would not simply be cropped. Project pages are assembled from project files and can easily be extended.

The website was developed through vibe coding. I learned how to describe ideas with AI, write code, review the results and keep changing them until they felt right. The site is built with VitePress, Vue 3, TypeScript and Tailwind CSS.

For me, vibe coding was both a way to build the site and a learning process in its own right. AI helped with development, while I made the decisions about structure, typography, colours, animation and the overall design.

## My contribution

The concept, design, texts, image selection, navigation and content decisions are mine. I built the website through vibe coding and developed it step by step.
